# Mystical.exe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native Windows shell for the dashboard — Mystical.app's twin for a bridge running in WSL — plus a global hotkey, built from WSL by `mystical app`.

**Architecture:** One C# WinForms process on the Windows side hosts the dashboard in WebView2, a tray icon, WinRT toasts, a floating panel and a named-pipe server; it reaches the bridge through `wsl.exe` (status, lifecycle, rebuild) and `http://127.0.0.1:<port>` (page, poll). The page talks to it through the same `window.Notification` shim and `mysticalNotify` handler the Mac app installs, so the dashboard's existing `lib/mac.ts` path carries both platforms. `windows/build.sh` stages the sources on the Windows side, publishes with `dotnet.exe`, installs, registers the `mystical://` scheme and rewrites the Startup `.cmd`.

**Tech Stack:** C# on the .NET SDK (8 floor, built with whatever is installed), WinForms, `Microsoft.Web.WebView2` 1.0.4258.31, `Windows.UI.Notifications` via the `windows10.0.19041.0` TFM, bash + python3 for `build.sh`, node 22 for the shim check, pytest for `startup.py`.

## Review Focus

- A `/local/running` status entry with no `label`, no `kind`, and no job title → the row reads "waiting on you", never an empty string or a crash. (Task 1, `Running` checks.)
- A capture or probe `dir` that is a `\\wsl.localhost\…` UNC path → accepted; a relative one → `{ok:false, error}`, nothing written. (Task 1, `CaptureRequest` checks; Task 7 wrapper.)
- A page `tag` longer than 64 characters → the toast still shows (Windows rejects long tags) and a repeat with the same tag still replaces it. (Task 1, `Shim.ToastTag` check.)
- A `set` message with an unknown key or a non-boolean value → "unknown setting" reply, prefs file untouched. (Task 1, `Prefs` checks; Task 5 op.)
- A `mystical://SESSION/ab%20c` link (uppercase host, encoded id) → opens session `ab c`; `mystical://restart` → ignored. (Task 1, `DeepLink` checks.)
